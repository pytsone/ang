# English Adventure

Prosty, kolorowy mini-game dla dzieci w wieku 7–9 lat.

## Co robi aplikacja?

- ćwiczy słówka z kategorii zwierząt,
- odtwarza angielską wymowę za pomocą Web Speech API,
- sprawdza poprawność odpowiedzi w trybie „Listen & Match”,
- zapisuje liczbę zdobytych gwiazdek w `localStorage`.

## Jak uruchomić lokalnie?

1. Pobierz repozytorium.
2. Otwórz folder w przeglądarce.
3. Uruchom `index.html` albo podłącz projekt do GitHub Pages.

## Jak działa GitHub Pages?

W repozytorium na głównym branchu należy umieścić pliki:

- `index.html`
- `style.css`
- `app.js`

Po podpięciu Pages z głównego brancha projekt będzie dostępny pod adresem:

https://pytsone.github.io/ang/

## Rozszerzenia do MVP

W kolejnych krokach można dodać:

- nowe kategorie: colors, food, school,
- fiszki audio,
- quiz z mikrofonem,
- odznaki i postęp dziecka,
- zapisywanie wyników dla wielu użytkowników.

## Technologia

- HTML + CSS + JavaScript
- Web Speech API (`speechSynthesis`)
- localStorage do zapisów postępu
